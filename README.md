# Portal de Transparencia y Difusión de Documentos Oficiales

> **Estado: Archivado / Sin mantenimiento activo.** 
> Este proyecto fue desarrollado para la difusión de documentos oficiales con integración a servicios en la nube (AWS S3/Firebase, según corresponda). El código se conserva como referencia técnica. Ya no recibe actualizaciones ni soporte.

## Descripción
Portal web de transparencia y difusión de documentos oficiales con integración a servicios en la nube.

## Tecnologías utilizadas
- HTML5, CSS3, JavaScript
- React, Node, Firebase, AWS, etc.
- Servicios en la nube para almacenamiento y distribución de documentos con social cards para interacción social.

## Notas
- Proyecto descontinuado. No se aceptan PRs ni issues.
- El código se mantiene público como referencia para futuros desarrollos.
